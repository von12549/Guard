# V4 Guards 1.1.3 release notes

V4 Guards 1.1.3 is a compatibility patch built directly from the immutable 1.1.2
release tag. It contains only the Build Evidence Provider child-process PATH
isolation fix and the metadata, tests and documentation required for this release.

## Fixed

- Every isolated `dotnet` child launched by the Build Evidence Provider now sets
  `DOTNET_ADD_GLOBAL_TOOLS_TO_PATH=0` beside its per-run `DOTNET_CLI_HOME`.
- Regression coverage verifies the child environment, confirms a real isolated
  build leaves the persisted Windows User PATH byte-identical, and rejects
  permanent User/Machine environment mutation APIs in guard runtime sources.

## Compatibility and exclusions

- Product version: `1.1.3`; stable API: `1.0`.
- Host and Web Companion assembly version: `1.1.3.0`.
- Built-in Profiles, module component versions, contracts and supported platforms
  are unchanged from 1.1.2.
- No C1-C6 candidate, inventory or incomplete `ifx_profile` content is included.
- This release does not modify User or Machine PATH and does not include or execute
  the separately developed PATH repair utility.
- Existing releases, installations and receipts remain immutable.
