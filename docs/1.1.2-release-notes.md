# V4 Guards 1.1.2 release notes

Version 1.1.2 fixes Architecture Conformance scan scope for Profiles that declare
`projectIdentity.relativeRoots`. Stage Host passes the validated list to the adapter;
the adapter scans only the declared project/source subtrees. Missing, escaping,
linked, overlapping and case-colliding roots fail closed. A project reference from
an included project to a file outside the declared union is a graph-completeness
finding. An omitted/empty list or sole `.` retains whole-TargetRoot behavior.

Product, Host and Companion versions are `1.1.2`; the stable CLI/API is `1.0`.
The changed built-in Architecture Conformance module is `1.0.1`. The 1.1.1
offline composition contract is unchanged, as are the prior released archives
and installations. No real `ifx_profile`, IFX bundle acceptance, composition,
workflow/ruleset activation, IFX cutover or V3 retirement is included.

This patch repairs the scope needed for a future IFX Profile. It does not implement
the remaining IFX detector families, G03/G04/G05 specialized gates, toolchain
prerequisites, baseline translation, complete Stage ownership or UI acceptance.
