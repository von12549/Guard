# V4 Guards 1.1.0

V4 Guards 1.1.0 is the first release to package the completed V4-P9 local Web Companion. It preserves
the stable V4 1.0 CLI/API contract and the Linux/Windows support boundary established by 1.0.0.

## Included

- a root project README that is required, package-hashed, archived and install-receipted;
- immutable embedded Web Companion assets with no loose runtime `wwwroot`;
- one-active-Target workspace selection and manual Stage execution;
- Host-owned Profile/readiness projections, run/evidence inspection and read-only Plan presentation;
- deterministic Host, package and Companion distribution provenance; and
- exact Windows-full and Linux-complete P9 certification coverage.

## Compatibility

- product, Host and Web Companion version: `1.1.0`;
- stable CLI/API version: `1.0`;
- unchanged built-in module and Profile component versions: `1.0.0`;
- certified targets: `linux-x64` and `win-x64`.

The Web Companion remains non-authoritative and loopback-only. Reset, authority/Plan editing, Target
mutation, Git/PR operations, remote access, arbitrary commands, automatic extension installation,
multi-project parallel execution and IFX-specific behavior are not included.

## IFX Profile baseline

The released 1.1.0 archive is the fixed initial baseline for the planned IFX Profile practice, parity
and cutover-readiness program. Test installations are derived from the release under the IFX repository
`guard/` directory. Any V4 defect found there is corrected in the source package first, recertified and
published as a `1.1.x` patch; the installed test copy is never treated as source authority.
