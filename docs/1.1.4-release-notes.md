# V4 Guards 1.1.4 release notes

V4 Guards 1.1.4 is a compatibility patch built directly from the immutable 1.1.3
release tag. It promotes reusable workspace evidence into the V4 Host and includes
the contracts, tests, integrity metadata and documentation required for the release.

## Added

- Profiles may opt into a schema-bound `workspaceEvidence` provider and output path.
- Before a stage runs, the Host performs one bounded, ordinal and link-safe projection
  of declared readable roots and writes a deterministic file inventory with SHA-256
  hashes and Target commit binding.
- Eligible modules receive the Host-controlled evidence path and hash through their
  child-process environment, so related checks can reuse the same trusted evidence.
- Contract and stage tests cover generation, capability gating, deterministic content,
  path safety and backward compatibility when the declaration is absent.

## Fixed

- The evidence-aware synthetic adapter safely handles an empty legacy module `config`
  object under PowerShell strict mode; P10 composition coverage proves the prior
  no-evidence execution path remains valid.
- P6 isolated local clones opt into Git for Windows long-path handling per child
  process, without changing any user, system or repository Git configuration.

## Compatibility and exclusions

- Product version: `1.1.4`; stable API: `1.0`.
- Host and Web Companion assembly version: `1.1.4.0`.
- Existing Profile behavior is unchanged unless `workspaceEvidence` is declared.
- Built-in module component versions and supported `linux-x64`/`win-x64` platforms
  remain unchanged.
- No IFX candidate, inventory or `ifx_profile` content is included. IFX adoption and
  platform policy remain separately reviewed decisions.
- Earlier tags, releases, installations and receipts remain immutable.
