# V4 Guards 1.1.2 local candidate — TargetRoot scan scope

Status: `LOCAL CANDIDATE — NOT PUBLISHED`

passes a Profile's `projectIdentity.relativeRoots` into module input. Architecture
Conformance validates those roots and scans only declared project/source subtrees.
Missing, escaping, linked, overlapping and case-colliding roots fail closed; an included
project's reference outside the declared union is a graph-completeness finding.
An absent/empty root list or sole `.` retains the previously published whole-TargetRoot
behavior. The built-in Architecture Conformance component advances to `1.0.1`.

This source change does not alter either published installation. It has not been
certified or published as a release, and does not approve the real IFX bundle. The
IFX candidate still lacks specialized gates and complete detector-family coverage.
