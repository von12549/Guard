# V4 Guards 1.1.2 candidate history — TargetRoot scan scope

This records the local candidate before the separately authorized 1.1.2 publication.
The final release state and constraints are in [1.1.2 release notes](1.1.2-release-notes.md).

The source candidate preserves API `1.0` and the 1.1.1 composition contract. Stage Host
passes a Profile's `projectIdentity.relativeRoots` into module input. Architecture
Conformance validates those roots and scans only declared project/source subtrees.
Missing, escaping, linked, overlapping and case-colliding roots fail closed; an included
project's reference outside the declared union is a graph-completeness finding.
An absent/empty root list or sole `.` retains the previously published whole-TargetRoot
behavior. The built-in Architecture Conformance component advances to `1.0.1`.

The candidate certification did not itself authorize publication or approve the real
IFX bundle. The bundle still lacks specialized gates and complete detector-family
coverage; the 1.1.2 base does not include it.
