# V4 Guards 1.1.6 release notes

V4 Guards 1.1.6 fixes the two known issues of 1.1.5. It is the stable base for consumer adoption. The
public CLI, query and schema contracts, built-in modules and Profiles and the four-root contract are
unchanged, and so is the Host and Web Companion source code.

## Fixed

- **Long paths in the trusted-base runner (V4-TODO-017).** Every Git command of
  `integrations/github/Invoke-V4TrustedBase.ps1` now passes `core.longpaths=true`, and the isolated target
  clone persists it. Before, on Windows, a tracked path longer than MAX_PATH could read as deleted and fail
  the HeadRoot or post-test tracked-file check. P6 has a regression case for it.
- **Build-location-independent builds (V4-TODO-018).** Independent Release builds of the same commit from
  different directories now produce a byte-identical archive. Before, the Host embedded its absolute PDB
  path, and the Web Companion shipped a static web assets manifest with the absolute source `wwwroot` path.
  - The Host is built without debug information, as the Web Companion already was. Release archives never
    contained a Host PDB.
  - Both projects map the repository root to `/_/`.
  - The Web Companion no longer builds static web assets manifests. It serves its UI only from embedded
    resources, as before.
  - P7 builds a second clone at another location and requires the same archive.

## Changed

- The archive no longer contains `companion/v4-web-companion.staticwebassets.runtime.json` or
  `companion/v4-web-companion.staticwebassets.endpoints.json`. It has 140 entries instead of 142.
- The Host PE debug directory contains only the `Reproducible` entry.
- Version metadata: product version `1.1.6`. Host and Web Companion assembly version `1.1.6.0`.

## Compatibility

- Stable API: `1.0`.
- Supported platforms: `linux-x64` and `win-x64`. Prerequisites are unchanged: PowerShell 7.4+ and .NET 10.x.
- Installation, verified uninstall and offline bundle composition work as in 1.1.5. Install 1.1.6 as a new
  sibling installation. 1.1.5 and earlier releases stay immutable.
- Schema `$id` values keep their historical `https://ifx.local/v4/...` namespace.

## Known issues

None carried over from 1.1.5.
