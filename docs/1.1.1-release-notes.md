# V4 Guards 1.1.1 candidate notes

Status: local source candidate only. No `v4-guards-v1.1.1` tag or GitHub Release is authorized.

The candidate adds explicit offline composition of a reviewed Profile/module extension bundle into
a new sibling installation. Four public JSON schemas bind the bundle, independent review record,
composition manifest and external composition receipt. The composer verifies the installed base
and archive, checks hashes, schemas, IDs, capabilities and prerequisites, and refuses overlapping
roots. The read-only verifier checks the complete installed file inventory and both provenance
layers. The receipted Web Companion launcher verifies these inputs before starting the unchanged
Host-backed loopback UI.

Product, Host and Companion candidate versions are `1.1.1`; stable CLI/API is `1.0`. Built-in module
and Profile component versions remain `1.0.0`. The published 1.1.0 archive and installation remain
unchanged. No `ifx_profile`, real extension approval, remote installation, IFX cutover or workflow
activation is included. Full candidate certification and separate publication approval are pending.
