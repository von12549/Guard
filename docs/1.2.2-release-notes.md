# V4 Guards 1.2.2 repair notes

Status: published 2026-10-06 from source commit
`b56ca17ba60a8e9383931101077ad75cb129257f` as immutable tag `v4-guards-v1.2.2`.

This patch repairs the first-use path exposed by the IFX P03 human retest. The earlier P03 technical and
usability result stays FAIL. A1 and B3 evidence gaps remain, and IFX has not been adopted or protected.

- The Host distinguishes missing, expired, misbound, malformed and genuinely drifting safety proofs.
  Expiry is visible at its exact UTC boundary. Renewal is explicit, retains the previous proof bytes,
  and invalidates old Previews. Apply checks the proof again before StateRoot writes.
- The Companion replaces stale machine/status/recovery rows after a refused action, refreshes Host
  progress, and ignores responses superseded by newer form or Target changes.
- First onboarding shows one step's inputs, the four actual root paths, proof lifetime, planned and
  actual StateRoot files. Stage Runner and advanced inspection start collapsed. Graph-only selection
  carries no unused framework or project-reference policy.
- A verified preflight entry checks package identity and link-free, non-overlapping roots before install;
  records hash-only host and Target baselines; prepares fresh external directories only on explicit
  `Prepare`; and supports independent `Checkpoint` comparisons after later operations. IDE process
  presence alone does not block an unrelated workspace. Target ordinary or ignored drift stops the run.
- The public Companion startup defaults to dynamic port `0` when omitted and prints the selected
  loopback address and fixed root boundaries.

The stable public command API remains `1.0`. The patch does not install a consumer Profile, accept human
policy, write a consumer Target, activate CI or remote enforcement, or claim IFX protection. Published
1.2.1 tags and assets remain unchanged. See the
[1.2.2 release Plan](plans/20261006-v4-guards-1-2-2-release.md) for the exact-commit gates and fixed asset matrix.
