# Historical V4 formal Plans

This directory holds **historical, read-only** copies of the generic V4 product formal Plan pairs that
were written while V4 incubated in the IFX repository (`von12549/IFX`, `docs/guards/plans/`). They
were copied byte-for-byte during V4-TODO-008 T4 from IFX commit
`80f7b6b65fb06897444a6a36c604c42c93c834e4`. The Git blob of every file equals its IFX source blob,
as recorded in `docs/migration/v4-todo-008/provenance-index.json`.

These records describe the past exactly as it was accepted:

- They still contain the original IFX-relative paths, such as `docs/guards/v4/...`,
  `docs/guards/plans/...` and `artifacts/guards/v4/...`, and IFX branch names such as
  `codex/v4-development-base`. These paths are historical and do not describe this repository's
  layout.
- Their status lines, authorizations and evidence references belong to the IFX incubation period.
- Do not edit these files to match the standalone layout. New Guard formal Plans live directly in
  `docs/plans/`.
- Some older pairs use the V3 formal Plan format (`areaIds`). The V4 Host presents them as V3-historical
  Plans.

IFX adoption, Profile, bundle, P10 and cutover formal Plans remain in IFX and are not copied here.
